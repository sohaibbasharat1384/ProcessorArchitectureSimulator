# شبیه‌ساز معماری پردازنده (Processor Architecture Simulator)

یک شبیه‌ساز آموزشی و تعاملی که اجزای یک پردازندهٔ سادهٔ ۱۶ بیتی را **تک‌به‌تک** و **به‌صورت متحرک** شبیه‌سازی می‌کند.
رابط کاربری فارسی است، هیچ وابستگی‌ای ندارد و مستقیماً در مرورگر اجرا می‌شود.

هر بخش یک نمودار گرافیکی (SVG) دارد و هر عملیات به **ریزگام‌های دقیق** شکسته شده است: مقدارها به‌صورت برچسب‌های متحرک
روی سیم‌ها و گذرگاه‌ها حرکت می‌کنند و هر گام توضیح می‌دهد دقیقاً چه اتفاقی می‌افتد. با «گام بعدی» جلو بروید، با «گام قبلی» برگردید
یا «پخش خودکار» را بزنید؛ سرعت انیمیشن از بالای صفحه قابل تنظیم است.

## اجرا

فایل `index.html` را در مرورگر باز کنید. یا یک سرور ساده بالا بیاورید:

```bash
python3 -m http.server 8000
```

سپس به آدرس `http://localhost:8000` بروید.

## بخش‌ها

| # | بخش | چه چیزی شبیه‌سازی می‌شود |
|---|-----|---------------------------|
| 1 | واحد محاسبه و منطق (ALU) | زنجیرهٔ تمام‌جمع‌کننده‌ها و گیت‌های XOR تفریق، گیت منطقی هر بیت، شیفت‌دهندهٔ متحرک؛ یک گام برای هر بیت و هر پرچم Z/N/C/V |
| 2 | بانک ثبات | رمزگشای ۳ به ۸، گیت‌های AND با RegWrite، لبهٔ ساعت، و دو MUX خواندن ۸ به ۱؛ R0 همیشه صفر |
| 3 | حافظهٔ اصلی و گذرگاه | حرکت آدرس و داده روی گذرگاه‌ها، MAR و MDR، رمزگشای سطر و MUX ستون، چرخه‌های انتظار |
| 4 | حافظهٔ نهان (Cache) | تقسیم آدرس به tag/index/offset، انتخاب مجموعه، مقایسه‌گر هر راه، انتخاب قربانی (LRU/FIFO/تصادفی)، بیرون‌رانی و آوردن بلوک؛ نرخ برخورد و AMAT |
| 5 | واحد کنترل و رمزگشایی | رمزگشای opcode و ماتریس سیگنال‌ها (مانند PLA)؛ تولید تک‌تک سیگنال‌ها همراه با دلیل؛ کنترل ALU از روی funct |
| 6 | پردازندهٔ کامل (مسیر داده) | اجرای برنامهٔ اسمبلی در ریزگام‌ها: حرکت مقدار روی هر سیم، سیگنال‌های کنترل خط‌چین، به‌روزرسانی IR/ثبات‌ها/حافظه/PC در لحظهٔ واقعی |
| 7 | خط لوله | کارت دستورها که بین ۵ مرحله حرکت می‌کنند، حباب، توقف، تخلیه، فلش‌های پیشرانی و پرش، توضیح کار هر مرحله در هر چرخه، نمودار زمانی و CPI |
| 8 | پیش‌بینی پرش | ماشین حالت متحرک ۱ و ۲ بیتی، ثبات تاریخچه و جدول الگو؛ سه گام برای هر پرش (پیش‌بینی، حل شدن، به‌روزرسانی) |

## مجموعه‌دستورالعمل (ISA)

- ۸ ثبات `R0..R7` (۱۶ بیتی؛ `R0` همیشه صفر است)، حافظهٔ ۲۵۶ کلمهٔ ۱۶ بیتی (فون نویمان: دستور و داده در یک حافظه)
- دستورهای ۱۶ بیتی:

```
R-type : [15:12]=0001 [11:9]=rd [8:6]=rs [5:3]=rt [2:0]=funct   ADD SUB AND OR XOR SLT SHL SHR
I-type : [15:12]=op   [11:9]=rd [8:6]=rs [5:0]=imm6            ADDI LW SW BEQ BNE
L-type : [15:12]=0011 [11:9]=rd [8:0]=imm9                     LI
J-type : [15:12]=1000 [11:0]=addr                              JMP
         0000 = NOP, 1111 = HALT
```

نمونهٔ برنامه:

```asm
; sum = 1 + 2 + ... + 10
        LI   R1, 10
        LI   R2, 0
loop:   ADD  R2, R2, R1
        ADDI R1, R1, -1
        BNE  R1, R0, loop
        LI   R4, result
        SW   R2, 0(R4)
        HALT
result: .word 0
```

## آزمون‌ها

```bash

```

آزمون‌ها، علاوه بر بررسی هر بخش، همهٔ برنامه‌های نمونه را روی پردازندهٔ تک‌چرخه‌ای و خط لوله (با و بدون پیشرانی) اجرا می‌کنند
و بررسی می‌کنند وضعیت نهایی ثبات‌ها و حافظه در هر سه مدل یکسان باشد.

---

**English summary:** an interactive, dependency-free, browser-based simulator (Persian UI) of a simple 16-bit processor.
Each part of the architecture has its own animated tab, broken into fine-grained steps you can play, step forward or step back through: ALU, register file, memory and bus, cache, control unit, full datapath, 5-stage pipeline
with forwarding/stalls/flushes, and branch predictors. Open `index.html` to use it; run `npm test` for the test suite.
